## 📊 Admin Dashboard (Main Hub)
**Preview:** `admin_dashboard_preview.png`
The command center for administrators, providing real-time insights.

### Key Metrics (KPI Cards)
- **Total Leads:** Cumulative count of all leads in the system
- **Leads This Month:** Growth tracking with month-over-month comparison
- **Follow-ups:** Critical action items needing attention
- **Pending Leads:** Unassigned or new leads waiting for distribution
- **Monthly Revenue:** Real-time revenue tracking from closed deals
- **Conversion Rate:** Overall team performance indicator

### Data Visualization
- **Leads by Status (Pie Chart):** Visual distribution of Fresh, Follow-up, Closed, and Dead leads
- **Top Performers (Bar Chart):** Competitive ranking of top salespeople by revenue/deals

### Feature Highlights
- **Real-time Updates:** Metrics refresh automatically
- **Responsive Grid:** Adapts to any screen size
- **Quick Actions:** Direct access to common tasks from sidebar

## 📤 Lead Management
**Preview:** `upload_leads_page.png` & `all_leads_page.png`

### Bulk Upload
- **Drag & Drop Interface:** Easy file uploading
- **Format Support:** CSV, Excel (.xlsx, .xls)
- **Smart Parsing:** Auto-detection of columns
- **Auto-Distribution:** Round-robin assignment algorithm triggers automatically

### Leads List View
- **Advanced Filtering:** Filter by status, date, or salesperson
- **Search:** Instant search across name, email, phone, company
- **Status Badges:** Color-coded for quick visual scanning
  - ⚪ Fresh
  - 🟠 Follow-up
  - 🟢 Closed
  - 🔴 Dead
- **Quick Actions:** Edit, delete, or reassignment from the list

## 🎨 UI/UX Design Philosophy

### **Color System**
- **Primary Blue:** Trust, professionalism (Headers, Primary Buttons)
- **Success Green:** Closed deals, positive growth (Badges, Charts)
- **Warning Orange:** Follow-ups, attention needed (Badges, Alerts)
- **Danger Red:** Dead leads, critical issues (Deactivate, Delete)
- **Neutral Grays:** Backgrounds, text hierarchy

### **Layout Principles**
- **Sidebar Navigation:** Persistent access to all modules
- **Card-Based UI:** Distinct content grouping with clear visual hierarchy
- **Responsive Design:** Fully functional on Desktop, Tablet, and Mobile
- **Feedback:** Toast notifications for all actions (Success, Error, specialized alerts)
